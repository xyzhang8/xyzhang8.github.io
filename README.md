# Portfolio, Xin Yue Zhang

Personal site. Static, no build step, no dependencies.

```
index.html    the site, one scrolling page
resume.html   embedded PDF viewer, opens in a new tab
styles.css    all styling, theme colours are the variables at the top
nav.js        highlights the nav link for the section in view
media/        images, video and the vectorised handwriting
```
