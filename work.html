Depth from blur

MSc thesis

Super-resolution microscopy reaches a resolution the optics alone should not allow, but only if you know how far a feature sits from the focal plane. Working within my research team, I built the validation pipeline for the simulations: ground truth in, reconstructed depth out, error measured across the parameter range.

Against a conventional calibration, the error in depth determination fell by up to 99 percent in simulation. I came to the problem from mechanical engineering and control, and learned the microscopy on the way in.

The indicators that never turned green

Batenburg Bellt

A client's production monitoring system carried PLC signals through services and a MySQL database to an operator screen. Two status indicators stayed dark while both processes were visibly running on the floor.

I put the code, the configuration and the PLC address documentation side by side and found a database table mapping the signals to the wrong addresses. The fix was corrected rows — no application code touched. I was in front of the client in my first week.
