The indicators that never turned green

Batenburg Bellt

A production monitoring system showed two processes as idle while they were plainly running on the floor. Reading the code, the configuration and the PLC address documentation side by side turned up a database table mapping signals to the wrong addresses. Fixed in the data, with no change to application code.
